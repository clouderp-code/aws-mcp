# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2024-01-01

### Added
- Initial implementation of TMF ODA Transformer MCP Server
- `schema-analyzer` tool for analyzing schema files for TMF ODA transformation
- `db-analyzer` tool for analyzing database structures for TMF ODA compliance
- Support for multiple database types (PostgreSQL, MySQL, MongoDB)
- Support for various schema formats (JSON Schema, OpenAPI, Avro)
- Comprehensive TMF ODA component type analysis
- Security best practices implementation
- Detailed documentation and usage examples
